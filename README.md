# 稳定币理财收益计算器

**在线使用 → https://biteyeai.github.io/stablecoin-yield/**

交易所理财页上写着 10%、12% 的年化，大多只覆盖前几百到几万 U，超出的部分会掉到 2%～4%。这个计算器把 7 家交易所的稳定币理财产品放在一起，按每家官方公布的阶梯利率逐段计算，告诉你手上的钱存在哪里，到期实际能拿多少。

由 [Biteye](https://x.com/BiteyeCN) 整理制作。

## 怎么用

1. 输入本金（美元），选择存期（7 / 30 / 90 / 180 / 365 天）和币种。
2. 点「查询」。
3. 看结果：
   - **推荐存入**：只存一家时收益最高的产品，附带分段计算过程。
   - **分开存**：如果拆开存能多赚，会给出最多三家交易所的最优组合，以及每一笔存哪、存多少、能拿多少。
   - **排名**：所有产品按实际年化从高到低排列。

勾选「包含新用户 / VIP 专享」，会把只对新用户或 VIP 开放的产品也算进去。

## 收录了哪些产品

- **交易所**：币安、OKX、Bybit、Bitget、Gate、MEXC、HTX
- **范围**：各家理财页上全部美元稳定币（USDT、USDC、U、USD1、USDE、USDD 等）的活期和定期产品，年化 1% 以上
- **不包含**：双币、鲨鱼鳍等结构化产品；链上赚币；2～3 天的新用户体验产品
- **数据时间**：2026 年 11 月 3 日，取自各交易所官方理财页、活动公告和公开接口

## 计算方式

- **按阶梯逐段计算。** 例如某产品前 1,000 U 年化 11.85%、之后 3.85%，存 10,000 U 的年收益 = 1,000 × 11.85% + 9,000 × 3.85% = 465 U，综合年化 4.65%。
- **存期收益 = 年收益 × 天数 ÷ 365**，不计复利。
- **OKX 活期**：官方 FAQ 写明收益扣除 15%，已按扣费后的利率计算。
- **HTX 限时加息、"暖冬同行" 7 天定期和 Gate "疯狂星期三"**：单人额度需登录才能看到，只列在明细表里，不参与计算。
- **默认按普通用户计算**，并假设全部本金都是新充值的（Gate 闲钱宝加息要看活动期内的净充值）。

## 使用前请注意

- **利率随时在变。** 活期利率实时浮动，活动额度先到先得，申购前请以交易所页面为准。
- **部分奖励不是稳定币。** Gate 余币宝 USDT 的 7.89% 里有 5% 以 GT 发放，USD1 部分产品的利息以 WLFI 发放，页面上都有标注。
- **地区限制。** MEXC 用户协议将中国大陆列为禁止服务地区。各交易所的活动对部分国家和地区不开放，请自行确认。
- **不构成投资建议。** 存放在交易所的资产有平台风险，请自行判断。
